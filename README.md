# mynote

React + TypeScript + Ant Design 的纯前端本地资料库。

## 使用

双击 `dist/index.html`，或桌面“mynote”快捷方式。没有 CMD、PowerShell、后台服务或监听端口，也不需要安装运行环境或联网。使用 Chrome / Edge 普通模式。首次打开点击“选择 .shiye 文件夹”，选中 `C:\Users\<用户名>\.shiye` 并允许读写。应用在该目录创建加密索引 `index.shiye` 和 `content/` 资料文件夹；浏览器可能在重新打开时要求再次授权。

首次使用设置至少 8 位资料库密码。成功登录后，本浏览器 30 天内自动解锁，期限从输入密码登录时计算，自动打开不会延长。点击“锁定”会立即清除免密记忆。新建笔记支持文字、Markdown 标题/表格/代码块；表格中的密码或登录信息列默认遮挡。编辑时可粘贴截图、拖入图片或多选图片，支持 PNG / JPG / WebP / GIF，单张不超过 5 MB。图片标记可调整图文顺序，保存后点击图片放大。支持搜索、标签、编辑、复制、删除、锁定与备份。

默认使用 One Dark。侧栏顶部可切换 One Dark、浅色和 Nord，选择会自动保存在当前浏览器。笔记列表可通过侧边栏边缘的箭头收起或展开；标签筛选及备份入口位于列表中。编辑时点击“预览”可开启左侧编辑、右侧实时预览，窄屏自动上下排列。

编辑笔记时可粘贴或拖入文件，也可点击“添加附件”多选任意类型文件（如 docx、zip）。单个附件上限 20 MB，随笔记加密保存并包含在备份内，可在笔记中下载或移除。浏览器未提供剪贴板文件时，可改用拖入或文件选择。支持仅含附件的笔记。

## 数据与备份

资料通过 PBKDF2-SHA256（310,000 次）派生密钥，使用 AES-256-GCM 分别加密：`index.shiye` 保存加密索引，`content/*.note` 保存每篇笔记，`content/*.bin` 保存图片和附件的原始二进制加密内容。文件名使用随机标识，不暴露笔记标题和附件名称。每次修改只写变化的笔记和小索引，未修改的附件不读取、不重写。附件列表只在内存保留元数据；图片、HTML 和下载按需读取。解锁密码不写入磁盘，不上传数据。

浏览器 IndexedDB 继续保存目录句柄、30 天免密使用的不可导出 CryptoKey 和到期时间。旧版保存在 IndexedDB 的资料，在原浏览器解锁后自动迁移；旧浏览器副本保留。之后的日常保存以加密文件目录为准。

清理浏览器数据会丢失目录授权和免密记忆，不会删除外部资料文件；重新选择原目录并输入资料库密码即可读取。忘记密码仍无法找回。免密期间能使用此浏览器配置的人也能打开资料。加密备份不包含目录授权和免密信息。

保存完成后才会显示成功。索引使用独占写入和关闭时替换，每次提交前检查资料版本。新笔记和附件文件写入并逐字节校验后才提交索引；失败时原索引和原资料继续有效。提交成功后清理不再引用的旧文件。突然断电可能留下未引用的加密文件，不影响已提交资料。关闭应用后可直接复制整个 `.shiye` 目录备份或迁移，也可继续导出 `.shiye` 加密备份。为兼容便携备份，资料按 JSON 和附件 Base64 等效体积计算，上限 100 MB，单张预览图片 5 MB，单个附件 20 MB。

`.shiye` 备份含完整图文，知道密码即可跨电脑导入。导入会合并笔记，内容不同的同 ID 笔记作为副本保留。旧窗口覆盖会被拒绝，请保留改动后刷新。

## 开发与构建

```powershell
npm ci
npm run build
npm test
npm run benchmark
```

开发测试使用 Node.js 24+。`build` 先执行 TypeScript 检查，再由 esbuild 把 JS / CSS 和 HTML 预览所用的 Excel 库内嵌到 `dist/index.html`。浏览器版不包含 SQLite 或 WebAssembly 引擎。无 CDN、外链字体、运行时请求或后台服务；CSP 禁止网络连接。`node_modules` 和 Node.js 仅用于开发构建和测试。测试包含增量文件写入、附件延迟读取、索引提交失败保护、旧数据迁移、加密及附件完整性。性能检查使用模拟附件，不访问用户资料。

## SQLite 版迁移

如果目录中只有旧版 `shiye.sqlite`，先关闭旧页面，然后使用 Node.js 24+ 执行一次：

```powershell
node scripts/migrate-sqlite.mjs "C:\Users\<用户名>\.shiye"
```

该工具只读 SQLite，将其中原有密文复制为 `migration.shiye`，不解密、不修改原数据库。新版首次解锁后自动拆分迁移，完成后创建 `index.shiye`。原 SQLite、迁移文件继续保留，可作为迁移前备份。迁移后旧页面的写入不会同步到新版，请关闭旧页面；`index.shiye` 是目录索引，不能作为单文件备份，跨电脑使用侧栏的“导出备份”或复制整个目录。

## 更早版本迁移

旧版 `data.vault` 是 Windows DPAPI 格式，浏览器不能直接解密。旧文件会保留，现有加密文件另存于 `legacy_backup/`，该目录已排除 Git 跟踪。

在原 Windows 账户中执行一次：

```powershell
npm run migrate -- ".\legacy_backup\data.vault"
```

按提示输入新的迁移备份密码（不会回显），生成 `旧版资料迁移.shiye`，然后在新版中导入。转换过程只在内存中处理明文，不修改旧文件、不生成明文 JSON。这是可选的一次性迁移工具，不是应用运行依赖。

## HTML 预览

编辑时点击“插入 HTML”选择 .html/.htm 文件。支持隔离预览、放大和下载。业务系统工作台的待办在编辑状态下随笔记保存，查看状态下直接保存到对应笔记文件。原独立 HTML 中已有的待办需先导出备份，再在内嵌页面导入。外部资源不联网加载，原页面的 Excel 库已离线内置。
预览支持代码块语法高亮（可在代码围栏后指定 ts、sql、bash、java 等语言），并随主题切换颜色。正文支持 **加粗**、`行内代码` 和 ==重点高亮==。
切换笔记时保留当前窗口内各篇笔记的未保存编辑，标题圆点表示未保存。保存后清除对应圆点；取消会丢弃当前笔记的编辑。关闭或刷新页面前仍需保存，浏览器会对未保存内容给出离开提醒。
